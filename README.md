# FitGround
基于人体与服装测量约束的多模态合身度理解系统      Measurement-Grounded Multimodal Garment Fit Understanding  FitGround studies whether multimodal models genuinely understand garment fit through the physical relationship between body and garment measurements, rather than relying on visual appearance, garment identity, or dataset shortcuts.
